ce faci, in 6 pasi

Merge din orice disc: D:\video, C:\VIDEO, E:\orice - codul ia folderul unde e bat-ul.

  1. Descarca ZIP-ul (butonul verde)
  2. Click dreapta pe ZIP → Properties → Unblock → OK
  3. Click dreapta → Extract All → scrie D:\video
  4. Intra in folder → dublu-click pe RULEAZA.bat
  5. Lipeste linkul YouTube → Enter
  6. Asteapta 10-20 min → se deschide raportul

ce iese

  1. VIDEO-raport.html - timeline cu toate planurile, taieturi, ritm
  2. VIDEO.xml - importi in FilmCraft: File → Import
  3. report.html - descompunerea shot cu shot (filmat / AI / 3D / cod)
  4. VIDEO.edl - il importi in Premiere sau DaVinci Resolve
